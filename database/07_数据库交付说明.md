## 四、Docker 部署

在交付包根目录执行：

```bash
docker build -f docker/Dockerfile -t diet-agent-pg:1.2r4 .
cd docker
POSTGRES_PASSWORD=你的密码 docker compose up -d
docker compose logs -f db
```

初始化顺序为：

```text
00 前置校验 → 10 恢复备份 → 20 数据库整改 → 30 权限 → 40 病种
→ 45 菜式扩充（38）→ 46 过敏原复核（39）→ 50 pgvector → 55 知识库 → 56 铁/纤维/钙 → 57 反向营养 → 60 汇总验收
```

向量结构会随容器初始化建立，但真实向量仍需在容器启动后按 `16_RAG对齐与灌库说明.md` 执行 `15_RAG灌库脚本.py`。

## 五、数据口径

- 食材营养数据按每 100 g 可食部记录，菜式按配料克数汇总；
- 本次补充的纤维以及部分钙来自公开同类食材数据，一级 `data_quality` 采用保守的 `approx`，具体来源保留在 `source_row.supplemental_nutrients`；
- 菜式纤维和钙为估算结果，没有计算烹饪损耗；扩充批次菜式复用食材的纤维待后续补录，当前快照键缺失不按 0 计算；
- 过敏原：`已确认含` 配料进入菜式 `strict_allergens` 硬排除；`确认不含` 仅表示不在本库过敏原词表内，不替代个体过敏史；`未核查` 食材引擎只打提示不硬排除，本包已清零；
- 反向营养映射只表达“可能相关”和“建议关注”，不能用于诊断；
- 反向营养映射在专业审核前保持 `review_status=pending`、`is_reviewed=false`、`is_active=false`。
