# 21号反向营养映射审核修订说明

本次只处理审核报告中与21号文件有关的内容，不修改19号知识库主题。

## 修改结果

- 原16条映射修订为13条；
- 仍覆盖钙、铁、锌、维生素A、维生素B1、维生素B2、维生素C七种关键微量营养素；
- 证据等级改为逐条填写：`moderate` 7条、`low` 6条；
- 13条记录全部保持 `review_status='pending'`、`is_reviewed=false`、`is_active=false`；
- 正式启用仍需专业审核人确认。

## 具体调整

| 原内容 | 调整后 | 原因 |
| --- | --- | --- |
| 容易疲劳、身体无力分别映射铁 | 合并为“容易疲劳”，身体无力等放入别名 | 两条含义接近，检索时容易重复召回 |
| 容易骨折映射钙 | 删除，骨质疏松并入“骨量偏低”别名 | 骨折是临床结局，不能直接判断为缺钙 |
| 舌头肿痛只映射B6 | 主映射调整为B2，说明中提示铁、B12、叶酸等其他可能因素 | 舌炎并非B6特异表现 |
| 普通记忆力下降映射B1 | 删除 | 一般记忆力下降不能直接指向B1缺乏 |
| 16条统一为moderate | 经典缺乏表现用moderate，低特异性表现用low | 避免证据等级过高 |
| Vitamin A来源链接大小写不统一 | 统一为`VitaminA-HealthProfessional` | 保持来源地址一致 |

## 关于01备份

01仍是v1.2r2基线备份，里面保存的是审核前16条记录。恢复01后必须继续执行新版21号脚本，Docker流程会在57步骤自动完成这项修订。新版21执行两次时，会先清理仍处于待审核、未启用状态的本批旧稿，因此不会叠加重复记录。
