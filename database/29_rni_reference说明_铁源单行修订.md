# 营养素参考摄入量表（RNI/DRIs）数据说明（全年龄段版）

> 本表是数据包的第六个库，为 Agent B 的 `calc_micro` 工具提供「按周对照微量营养素」的人群参考值。
> 数值对照中国营养学会官网《中国居民膳食营养素参考摄入量（2023版）》（DRIs 2023）表 1–表 23 原文图片逐条提取。
> 同时提供一份扁平化 CSV（`rni_reference_核查表.csv`）供人工逐行核查。

## 1. 这个库有什么用

`rni_reference.json` 提供 DRIs 2023 中「关键微量营养素」的参考值，用于：

- 周度汇总摄入量后，对照参考值判断**可能不足**（低于 RNI/AI）与**过量风险**（高于 UL）。
- 支撑需求 FR-11（按周对照 RNI，按性别/年龄）、FR-25（标注不足与过量）和 API-13（周报 RNI 对照）。

本表只做「摄入量 vs 参考值」的确定性对照，不用于诊断或处方。

## 2. 术语解释（AI / UL / type 是什么）

| 术语 | 全称 | 含义 |
| --- | --- | --- |
| **RNI** | 推荐摄入量（Recommended Nutrient Intake） | 能满足某人群中**绝大多数**（约 97–98%）个体需要的每日摄入量。作为「够不够」的对照基准。 |
| **AI** | 适宜摄入量（Adequate Intake） | 当证据不足以制定 RNI 时，用观察或实验得到的**人群适宜摄入量近似值**。功能上等同于 RNI 的使用方式。 |
| **UL** | 可耐受最高摄入量（Tolerable Upper Intake Level） | 每日可摄入、对健康人群几乎不产生毒副作用的**最高量**。超过即有「过量风险」。 |
| **`type` 字段** | — | 同一营养素在不同年龄可能用不同口径（如钙：成人是 RNI、婴儿是 AI）。`type` 在每条 value 上标明用的是哪一种。 |

> 判定规则：周摄入 `< value` → 可能不足；`> ul`（且 ul 存在）→ 过量风险。

## 3. 结构怎么看

顶层只保留 5 个字段：

| 顶层字段 | 含义 |
| --- | --- |
| `title` | 表名 |
| `source` / `source_url` | 数据来源（中国营养学会官网） |
| `notes` | 全局口径说明 |
| `nutrients[]` | 18 条营养素 |

每条营养素（`nutrients[]`）字段：

| 字段 | 含义 |
| --- | --- |
| `nutrient_id` | 稳定英文 ID，程序关联用 |
| `name` | 中文名称 |
| `unit` | 单位（注意 RAE / NE / α-TE 等折算口径） |
| `type` | 成人默认 `RNI` 或 `AI`；婴儿段在 value 层覆盖为 `AI` |
| `ul` | 成人默认 UL；`null` 表示无，不做过量判定 |
| `note` | 该营养素的分层 / 口径 / 特殊说明 |
| `values[]` | 全年龄段人群的参考值（447 行） |

`values[]` 每个元素：`sex`（male / female / both）+ `age_group` + `value`（RNI/AI 数值），并可带：

- `menstrual_status`：当前数据不再用于铁 · 女 50-64岁分行；该人群已并为单行 12 mg。
- `type`：覆盖营养素级类型（如 0-6月/7-12月 婴儿段 = AI；铁 7-12月 例外为 RNI）。
- `ul`：覆盖营养素级 UL；`null` = 该人群暂不做过量判定。
- `note`：该人群的特殊说明（如子年龄梯度取中值）。

## 6. 数据来源与提取方式（2026-10-19）

- 官网地址：<https://www.cnsoc.org/drpostand/>
- 官网以**图片**形式发布表格（表 1–表 23），WebFetch / 搜索引擎无法直接抽取数值，故下载图片后用 Windows OCR 逐表提取，并对关键列做高倍放大二次核对。
- 采用表格：表 9–表 12（18-29 / 30-49 男女）、表 13–表 14（50-64 男女）、表 20–表 23（65-74 / 75+ 男女）、表 15–表 17（孕早/中/晚）、表 18（哺乳期）；儿童/青少年表 1–表 8（0-6月、7-12月、1-3岁、4-6岁、7-8岁、9-11岁、12-14岁、15-17岁）。其中 0-6月/7-12月/1-3岁 已人工复核。

### 口径标注（2026-10-20）

- **维生素A**：本表单位为 μg RAE（2023 DRIs 官方口径）；食材表 `vitamin_a_ug` 为旧 RE 口径，植物性来源 RE 约为 RAE 的 2 倍，待食材表补 `vitamin_a_rae_ug` 派生字段后统一对照。
- **烟酸**：本表单位为 mg NE；食材表 `vitamin_b3_mg` 为纯烟酸（不含色氨酸转化），蛋白充足者对比会略低估约 20-30%，按近似处理。

## 8. 维护

- DRIs 出新版时，重新读图核对并更新本表；不影响食物成分表等其他库。
- 食物成分表新增营养列（如维生素 D、B6/B12/叶酸）后，在本表补对应条目即可。
- 本表「营养素 × 全年龄段人群」的嵌套结构以 JSON 为准；CSV 仅为人工核查用的扁平视图，改数据请改 JSON 后再重新导出。
