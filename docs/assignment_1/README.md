## 1. 需求分析文档（requirements/）

- **需求分析文档.pdf** —— 完整的软件需求规格说明书（SRS），依据 GB/T 9385-2008 编制。
- **images/** —— 文档中引用的全部图片，包括：项目标志、类图、时序图、界面原型、调研统计图表等。

## 2. 用户调研数据（survey/）

需求来源于真实调研，数据分为客观题与主观题两部分：

- **膳食搭配智能体系统用户调研问卷－默认报告.pdf** —— 问卷平台导出的默认报告，含客观题统计结果。
- **详细信息--第26题答案.xlsx / .csv** —— 主观题（第 26 题）的原始答案明细，共 47 份有效回答（`.csv` 供在线预览，内容相同）。

## 3. 智能体初步定制效果对比（agent-logs/）

本目录存放**初步定制阶段**的效果对比：对**同一输入（Prompt）**分别交由通用大模型与初步定制的智能体作答，用于演示定制前后的效果差异。此为本阶段的**阶段性结果演示，非最终交付版本**。

- **General.md** —— 通用大模型的原输出，以自然语言生成方案，缺乏确定性计算与数据溯源。
- **Custom.md** —— 初步定制智能体的原输出，体现领域知识 + 工具调用的定制效果，包括：
  - 确定性数值计算（BMR / TDEE / 宏量营养素配比）；
  - 硬性禁忌拦截（过敏、痛风嘌呤等级）；
  - 权威数据来源标注（《中国食物成分表》《成人高尿酸血症与痛风食养指南 2024》等）；
  - 双口径热量对比（生重食材 vs 含烹调油成品）。

> 本组为**初步定制**的效果对比案例，供验收时对照检查定制效果；后续将随开发迭代持续更新。
