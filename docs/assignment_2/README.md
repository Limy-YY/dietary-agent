## 3. 数据库交付包

面向后端与 Agent 开发的数据库交付包，PostgreSQL 18，为数据库设计说明提供支撑材料。目前版本为v1.1，设计文档基于此交付包和原型进一步设计了v1.2的数据库系统，我们后续会根据v1.2的设计对数据库进行更新。
核心文件：

| 文件                                   | 说明                                 |
| -------------------------------------- | ------------------------------------ |
| `00_数据库交付说明.md`               | 交付说明，含恢复步骤与 v1.1 更新说明 |
| `01_数据库结构.sql`                  | 建表、索引、约束、视图和函数         |
| `02_基础数据.sql`                    | 六类正式基础数据                     |
| `03_数据库备份_diet_agent_v1.1.dump` | 可直接恢复的数据库备份               |
| `05_数据库字段字典.csv`              | 最终数据库的 376 个字段              |
| `06_数据库外键关系.csv`              | 18 条外键关系                        |
| `07_数据来源与质量说明.md`           | 数据量、来源和已知缺失               |
| `08_数据库验收.sql`                  | 恢复后的验收脚本                     |
| `09_数据库安全配置.sql`              | 关闭默认公共权限                     |
| `10_Agent数据能力说明.md`            | 当前 Agent 可查询的数据能力说明      |

| `12_空库恢复测试结果.md`             | 两种恢复方式的测试结果               |
| `13_食材数据更新_v1.1.sql`           | 已有 v1.0 数据库的增量更新脚本       |
