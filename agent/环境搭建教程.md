# Agent 虚拟环境搭建教程

## 前提
- Python 3.10+（本机 3.12）
- 后端已在 8000 跑起、数据库 v1.2 已恢复
- 已拿到 DEEPSEEK_API_KEY

## 步骤（PowerShell，在 agent 目录）

```powershell
cd agent

# 1. 建虚拟环境（只需一次）
python -m venv .venv

# 2. 装依赖（国内镜像）
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple/

# 3. 配 .env
copy .env.example .env
```

编辑 `.env`，改这四行：

```env
DEEPSEEK_API_KEY=你的key
DEEPSEEK_MODEL=deepseek-v4-flash
BACKEND_BASE_URL=http://127.0.0.1:8000
DATABASE_URL=postgresql+psycopg://diet_app:diet_app_dev@localhost:5432/diet_agent
```

```powershell
# 4. 启动（8001）
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8001
```

## 验证
- 浏览器打开 `http://127.0.0.1:8001/health`，`llm` 应为 `true`

## 常见坑
| 现象 | 处理 |
|---|---|
| `python` 不是命令 | 换成 `py -3` |
| pip 慢 / 超时 | 已加镜像；仍慢就重试 |
| 装一半出错 | 删 `.venv`，从第 1 步重来 |

## 建好后能验证什么
- **三写落库**：对话 / 方案 / 档案真实写入数据库
- **SSE 对真 Agent 端到端**：真实模型产出（不再只能对样例断言结构）
